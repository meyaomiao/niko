# Niko

## Positioning

Niko is a lightweight desktop login and control application. Users sign in
once, select a model, and connect it to Claude Code, Codex, and other AI coding
assistants without editing configuration files.

## Brand Direction

The logo uses a friendly cat-head motif to make Niko approachable and easy to
recognize. It should feel like a calm desktop companion, not a chat bot or an
AI agent mascot.

The cat must have a proprietary silhouette rather than a generic symmetric cat
face. References to the letter `N` or the final `o` in `Niko` may appear as
secondary discoveries, but readability and visual charm come first.

## Naming

- Display name: `Niko`
- Keep this capitalization in the wordmark and product UI.
- Do not write the visible brand as `NIKO`, `Nico`, or `Neko`.
