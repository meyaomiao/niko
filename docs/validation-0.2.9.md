# Niko 0.2.9 实机验证记录

## 范围与方法

在 macOS 上使用已安装的 ChatGPT 26.1103.60933（build 25894，bundle identifier `com.openai.codex`）验证本轮 Niko 修复。用户授权了真实客户端测试，要求测试后恢复原样、验证通过后再更新安装包。

先正常退出 ChatGPT，再备份并校验配置、鉴权、相关数据库、会话数据、Niko 状态及 ChatGPT 应用数据。项目工作树未纳入测试写入范围。测试采用实际生产配置命令及真实 ChatGPT 界面，私密认证、备份和测试驱动均留在本机临时目录，不进入源码提交或发布产物。

## 实机发现并修复的问题

[目标应用进程控制](../src-tauri/src/commands/process.rs)原来仅等待五秒。较大的本地数据库在正常退出时可能需要更多时间，导致退出命令成功但 Niko 提前报告忙碌。现在允许最多三十秒完成正常退出，仍然不会强制结束应用，也不会在旧实例尚未退出时启动第二个实例。

新增两个不访问真实进程的回归用例，覆盖超过旧等待窗口后的成功重启，以及到达新期限后禁止重复启动。进程模块六项测试通过，实机修复后闭环通过。0.2.9 候选版本的相关原生回归共 99 项全部通过，`cargo check --locked --all-targets` 通过；[双端验证](../scripts/dual-verify.sh)的 Mac、Windows 类型检查、构建及各自 160 项前端测试全部通过。

## 验证边界
