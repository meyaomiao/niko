# Niko / MomoToken 客户端审查与完善记录

审查日期：2026-11-10。基线：`origin/main` / `ca50853`（Niko 0.2.8）。工作分支：`fix/momotoken-client-review`。

## 对正在使用的 ChatGPT 的影响

本次代码修改在独立源码工作区完成。初轮使用模拟 API/IPC 与临时配置进行隔离验证；随后按用户授权完成了真实本地 ChatGPT 的接入、对话、连接检查、启动/重启和恢复默认测试。实机操作前备份了相关配置、数据库及客户端状态，测试结束后逐项核对内容和权限，并恢复原来的官方账号模式；测试会话已移除，原 ChatGPT 已重新打开。本机 ChatGPT 安装包未替换，历史会话未迁移。

正式自动化回归仍只操作临时目录中的假配置。测试版的用户目录、备份目录、事务目录及日志目录统一隔离；未显式设置临时用户目录时直接停止，禁止回落到真实 HOME/APPDATA。实机验证所用的私密认证与临时驱动不进入正式提交和安装包。详见 [0.2.9 实机验证记录](validation-0.2.9.md)。

## 结论

第一轮发现的前端异步故障和原生 Codex 多文件回滚缺口均已落实修复。备份恢复映射、测速计时和诊断语义也已修正。后续实机验证又确认 ChatGPT 正常退出可能超过原来的五秒等待窗口，已延长至三十秒并完成复测。真实登录、可用分组的密钥申请、ChatGPT 模型请求、连接检查和恢复闭环均已验证；真实支付和历史会话迁移没有作为本次测试内容。

## 已完成的原生修复

### Codex 鉴权、模型配置与生效记录统一事务

[配置协调器](../src-tauri/src/commands/targets.rs)使用 v2 事务日志，将鉴权、模型配置和生效记录纳入同一批备份、写入和恢复。单个接入、批量接入、恢复默认共用协调器。所有配置先通过严格预检，再创建完整备份，完成写入和同步后才标记提交。

失败时先持久化回滚意图，再恢复整个集合；恢复完成另存终态，防止回滚中断或已提交日志清理失败时错误重做。已经持久提交的数据不会因清理中断而被当作写入失败。原文件不存在时，失败回滚也恢复原来的“不存在”状态。

旧 v1 无目标列表、v1 有目标列表两种日志布局分别保留，编号备份的含义不变。v2 对 Claude Desktop/CLI 共享路径稳定去重。未知版本、损坏日志或缺失备份会保留现场并拒绝继续写入。普通配置操作不重新触发历史会话迁移。

[配置合并与路径层](../src-tauri/src/targets/mod.rs)拒绝损坏 JSON/TOML，Codex 不再先改鉴权再发现配置无法解析。Grok 的 TOML 也按 TOML 预检，不再误按 JSON 处理。

注意：旧版本已经发生的部分写入，如果旧事务日志本来没有保存原鉴权或模型配置，升级无法凭空找回缺失的原始数据；兼容分支不会猜测或错配旧备份。

### 备份生成、列表与恢复共用映射

[备份模块](../src-tauri/src/commands/snapshots.rs)与写入事务共享配置路径，补齐 Claude 托管配置、Claude CLI、Grok、Antigravity，并兼容旧 `claude-code` 目录。只展示可以明确映射的普通备份文件；未知目标、未知文件、路径穿越、符号链接源及符号链接备份目录会被拒绝。

[设置页](../src/pages/Settings.tsx)展示原始配置文件名，使同一个应用的多份备份可区分。非法恢复请求在启动任何恢复流程前被拒绝。

### 测速与诊断准确性

[诊断模块](../src-tauri/src/commands/diagnostics.rs)解析 SSE 事件后才认定生成内容，支持跨 chunk 的 UTF-8、LF、CRLF、CR 和多行事件；角色声明、心跳、用量帧不计入首字。内容后的错误及失败终态会使本次采样失败；成功样本必须超过一半才展示中位数。SSE 事件及错误响应预览都有字节上限，错误预览做凭据脱敏。

无鉴权 HEAD 请求遇到 401/403 时表示“服务可达，但需要身份验证”，不能据此判定密钥失效。设置页明确说明该检查的范围；真正携带密钥的验证只把成功 HTTP 响应计为通过。

## 尚需专用环境验收的范围

早期命令行直连超时源于未使用本机已有系统代理。沿用系统代理后，MomoToken 公共接口、真实客户端登录、分组密钥申请和线上模型请求均正常。账号的 `default` 分组已被服务端弃用，实机测试按正常模型选择流程使用账号可用的 `codex-discount` 分组。

不同版本目标客户端、真实支付回调及历史会话迁移仍需单独验收。正式自动化回归继续使用临时目录和独立 CI 环境；任何实机修改都应先取得用户授权并完成可校验备份与恢复。
