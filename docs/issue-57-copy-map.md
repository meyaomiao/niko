## 价格展示

价格来自登录后的 `bootstrap.pricing` 和当前选中的模型服务；当前服务倍率只参与既有换算，不在主界面单独强调，也不推断速度、稳定性或线路质量。

- 文字量计费：沿用既有公式 `model_ratio * 2 * 当前服务倍率`，分别乘以输出、读取已保存内容和保存内容的既有比例。
- 按次计费：沿用后端的单次价格和当前服务倍率，显示为 `$金额 / 次`。
- 页面标签使用“你发出的内容”“AI 回复的内容”“读取已保存内容”“保存内容”，金额带 `$` 和 `/ 100 万 token`。
- `token` 只保留为必要计费单位，并解释为“模型计算文字量的单位”。
- 缺失、非法或不可计算的价格显示“价格暂不可用”；真实零价显示“免费”；大于零但低于 `$0.000001` 的价格显示为 `<$0.000001`，不显示误导性的 `$0` 或 `$0.00`。
- 余额仍使用后端 `quota` 与 `quota_per_unit` 换算；余额和充值金额不改协议或精度规则。

## 状态与下一步

| 当前状态 | 用户看到的提示 | 唯一步骤 |
| --- | --- | --- |
| 登录状态失效 | 登录状态已过期 | 重新登录后再试 |
| 余额不足 | 余额不足 | 先充值后再试 |
| 网络失败 | 网络连接失败 | 检查网络后重试 |
| 模型服务异常 | 模型服务暂时不可用 | 稍后重试 |
| 应用未安装 | 没有找到目标应用 | 安装并打开目标应用，再重新检查 |
| 接入尚未生效 | 接入还没有生效 | 先接入到应用，再检查 |
| 会话/账户数据为空 | 还没有找到可继续的会话、暂无使用记录或暂无充值记录 | 通过页面给出的重新读取、接入、充值等下一步继续 |
| 支付待确认 | 正在确认支付结果/订单仍在处理中 | 稍后重试查询或前往个人中心查看充值记录 |

## 官网

官网首页、登录/注册页、个人中心和支付回跳页与桌面端统一使用“接入到应用”“模型服务”“可恢复的备份”“使用明细”“连接密钥”。账户错误由 `website/src/js/api.js` 统一转换，普通页面不展示 HTTP 状态码、服务器原始错误、路径或完整凭证。

## 保留的必要术语

`token`（带通俗解释）、ChatGPT、Claude、模型名称、macOS/Windows、官方应用、SHA256 和支付平台名称属于用户需要识别的名称或准确技术信息，保留原词。`Provider`、`Profile`、`Base URL`、`API Key`、`quota`、`journal`、`WAL`、`SQLite`、`custom` 等内部词不作为普通用户可见文案。
