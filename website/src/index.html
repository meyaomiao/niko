为什么有 Niko

它不是另一个聊天窗口。

Niko 只负责把账号和模型安全地接入官方应用。真正的对话、代码与工具调用，仍然发生在 ChatGPT 或 Claude 里。少一层界面，也少一套需要维护的配置。

真实功能

从“想用”到“已经能用”，都放在一个流程里。

01

自动找到应用

检测本机已安装的 ChatGPT 与 Claude 桌面端，选中一个或全部应用后再接入。

02

选分组，也选模型

登录 Niko 账号后查看可用分组、模型、价格与兼容情况，再把选择写入目标应用。

03

写入前先留后路

修改配置前保存快照；需要退出接入时，可以恢复历史快照或官方默认配置。

04

配置后立即检查

启动或重启目标应用，并通过连通性测试确认当前配置是否真的可以请求模型。

05

日常信息不再分散

查看余额、用量与设备，完成充值、更新、主题切换、开机启动、托盘和脱敏日志导出。

设计理念

尽量少动，随时能退。

Niko 不在本地运行代理服务。协议适配由账户服务完成，客户端只修改接入所需字段，并尽量保留原有设置。

简单
登录、选应用、选模型、启用，一条清楚的主路径。
轻量
没有常驻本地网关，不再多维护一层代理。
可恢复
写入前保存快照，失败时回滚，也能恢复官方默认。
少暴露密钥
无需查看或复制 API Key；登录信息保存在系统凭证存储中。
