为什么有 Niko

它不是另一个聊天窗口。

Niko 只负责把账号和模型安全地接入官方应用。真正的对话、代码与工具调用，仍然发生在 ChatGPT 或 Claude 里。少一层界面，也少一套需要维护的接入设置。

真实功能

从“想用”到“已经能用”，都放在一个流程里。

01

检查应用是否已安装

检查本机已安装的 ChatGPT 与 Claude 桌面端，选中一个或全部应用后再接入。

02

选模型服务，也选模型

登录 Niko 账号后查看可用模型服务、模型、价格与兼容情况，再把选择接入目标应用。

03

写入前先留后路

修改设置前保存可恢复的备份；需要退出接入时，可以恢复备份或官方默认设置。

04

接入后检查是否能正常使用

启动或重启目标应用，并检查当前设置是否真的可以正常使用模型。

05

日常信息不再分散

查看余额、使用明细与设备，完成充值、更新、主题切换、开机启动、托盘和脱敏日志导出。

设计理念

尽量少动，随时能退。

Niko 不在本地运行代理服务。不同应用的连接方式由账户服务处理，客户端只修改接入所需设置，并尽量保留原有内容。

简单
登录、选应用、选模型、接入到应用，一条清楚的主路径。
轻量
没有常驻本地网关，不再多维护一层代理。
可恢复
修改前保存可恢复的备份，失败时保留原设置，也能恢复官方默认。
少暴露密钥
无需查看或复制连接密钥；登录信息保存在系统的安全存储中。
